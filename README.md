# 📇 コンビニはがき名刺ジェネレーター (Hagaki Meishi Maker)

緊急で名刺が必要になったとき、**セブン-イレブン等のコンビニマルチコピー機（はがきプリント用紙）を使って、高品質な名刺を即座に作成・印刷するツール**です。

通常のはがきサイズ（100mm × 148mm）に、日本の標準名刺サイズ（91mm × 55mm）を**2枚中央配置**し、定規とカッターで綺麗に切り離せる**トンボ（トリムマーク・裁断線）**付きの高解像度画像（600DPI）およびPDFを生成します。

---

## ⚡ クイックスタート（用途に合わせて選べる3つの方法）

### 方法1: ブラウザ画面でプレビューしながら作る（おすすめ！）
画面上で文字を打ち替えたり、手持ちの画像をドラッグ＆ドロップしてリアルタイムで仕上がりを確認できます。

**🌟 新機能:**
- **「🎯 名前ど真ん中」ワンクリック配置**: 氏名を中央に大きく据えたバランスの良いデザインを瞬時に適用できます。
- **マウスで自由配置（ドラッグ＆ドロップ）**: プレビュー上の「氏名」「肩書」「会社名」「連絡先」「QRコード」をクリックして掴み、好きな位置に自由に動かせます。中央に近づくとスナップガイド（赤線）が表示されます。
- **位置・揃え微調整バー**: 「水平中央」「垂直中央」「左/中/右揃え」「文字サイズスライダー」で自在に調整可能。

```bash
cd /home/kon_some/programing/hagaki_meishi
python3 meishi_maker.py web
```
ブラウザが自動的に開き、プレビュー画面が表示されます（またはブラウザで `http://localhost:8080` を開く）。
※直接 `web/index.html` をブラウザでダブルクリックして開くだけでも動作します！

---

### 方法2: 手持ちの名刺画像（オモテ・ウラ）をはがきに配置する（CLI）

すでにCanvaやスマホ、Illustrator等で作った名刺画像（JPG / PNG）がある場合：

#### 表面（オモテ2枚）：
```bash
python3 meishi_maker.py layout --card your_front_card.png -o output/front.png
```

#### 裏面（ウラ2枚・印刷ズレ防止180度回転）：
```bash
python3 meishi_maker.py layout --card your_back_card.png --rotate-180 -o output/back.png
```

※上段と下段で別の画像を配置したい場合：
```bash
python3 meishi_maker.py layout --top card1.png --bottom card2.png -o output/mixed.png
```

---

### 方法3: コマンド一発で文字情報から名刺を自動作成する（CLI）

デザインソフトが手元にない場合でも、氏名や連絡先を指定するだけで綺麗な名刺を自動生成してはがきに2面付けします：

```bash
python3 meishi_maker.py create \
  --name "山田 太郎" \
  --kana "Taro Yamada" \
  --company "株式会社サンプル" \
  --title "代表取締役 / エンジニア" \
  --tel "090-1234-5678" \
  --email "yamada@example.com" \
  --url "https://example.com" \
  --style modern \
  --output output/my_meishi.png \
  --pdf
```
（`--url` を指定すると、自動的に右下にアクセス用QRコードが配置されます）

対話形式で入力したい場合は、引数なしで実行するだけです：
```bash
python3 meishi_maker.py
```

## 🖨️ セブン-イレブンでの印刷完全マニュアル

### 1. 準備・スマホアプリの登録
1. スマホアプリ**「セブン-イレブン マルチコピー」**（無料）をインストール。
2. アプリを開き、**[はがきプリント]** → **[アプリでプリント設定]** → **[そのままプリント]** を選択。
3. 生成した画像（表面画像、および裏面画像）を選択します。
4. **⚠️【最重要ポイント】**
   - 設定画面にある**「ちょっと小さめ」は必ず【OFF（そのまま）】**にしてください！
   - ONにしてしまうと、91×55mmの原寸より縮小されて印刷されてしまいます。
5. カラー（60円）または白黒（20円）を選択し、**QRコードを生成・保存**します。

### 2. 用紙について
- **備え付け用紙を使う場合**:
  セブンのマルチコピー機にはがきトレイがあり、備え付けの私製はがき用紙（無地）で印刷できます。
- **用紙を持ち込む場合**:
  文具店等で「レーザープリンター対応はがき」「厚さ180kg以上（官製はがき程度〜それ以上）」の用紙を持ち込むと、しっかりしたコシのある名刺に仕上がります。

### 3. 両面印刷の極意（裏表のズレを防ぐテクニック）
マルチコピー機は給紙の特性上、左右どちらかにわずかに印刷位置が寄るクセが生じることがあります。以下の手順でズレを相殺できます：

1. **表面の印刷**:
   - 通常通りプリントします。
2. **裏面の印刷**:
   - 画像は本ツールで**「`--rotate-180`（裏面用180度回転）」**を有効にして書き出したものを使用。
   - 表面が印刷されたはがきを、**【天地（上下）を逆にして】**、白い裏面が印字面になるようトレイにセットします。
   - これにより、コピー機の左右の寄りクセが表面と裏面で一致し、ピッタリ位置が合います！

## ✂️ 綺麗なカッティング（切り離し）手順

### 用意するもの
- カッターマット（なければ厚紙や段ボール）
- カッターナイフ（刃を1段折って新しい刃にしておく）
- カッター定規（金属フチ付きがベスト）

### カットする順番
本ツールが出力する画像の外側には、定規を合わせるための**トンボ線（トリムマーク）**が付いています：

1. **左右の縦カット（2回）**:
   用紙の上下端にある縦のトンボ線に定規を合わせ、左右の余白（4.5mmずつ）を切り落とします。
2. **上下の横カット（2回）**:
   上下のトンボ線に定規を合わせ、上下の余白（19mmずつ）を切り落とします。
3. **中央の横カット（1回）**:
   名刺と名刺の境目（左右のトンボ線）に定規を合わせ、真ん中をスパッと切ります。

たった**5回のカット**で、角がピシッと立った 91mm × 55mm の標準名刺が2枚完成します！
（※角丸にしたい場合は「かどまるPRO」等の角丸パンチを使うとさらにプロ級の仕上がりになります）
